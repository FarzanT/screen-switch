# Changelog

## 0.3

- Public project name: ScreenSwitch.
- Two menu actions: Laptop screen only and Restore external screen.
- A visible Screen menu item, explicitly installed during startup.
- Original display modes, bounds, and mirroring retained for restoration.
- External-only enablement transactions and explicit cached-ID reconnect.
- Eight controller tests; optional hardware tests for mirrored and extended modes.

Prior development builds were named Laptop Only. Version 0.1's bundled configuration request failed with macOS error 1001. Version 0.2 separated external enablement changes and reconnects. Source publication does not claim broad hardware compatibility.
